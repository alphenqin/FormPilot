# FormPilot

AI 智能求职与网申自动化平台。M0 已通过工程验证；M1 个人经历资料库已实现，真实简历验收仍待完成；用户已授权先推进 M2，通用表单扫描与快照已实现，官方招聘实际申请表仍待验证。用户已授权推进 M3，填充计划、补答、冲突审核与版本批准已实现；M4 原生填写、稳定回读、停止/重试和条件撤销已实现，本地工程验证通过（153 项测试通过、1 项跳过）；小米真实申请表验收仍待完成。M5.1 已按用户选择实现 JD 解析、岗位条件审阅和本地经历证据匹配；操作见 [M5.1 使用指南](docs/M5_USER_GUIDE.md)。M5.2 已实现本地岗位简历的筛选、编排、审核、版本和导出，见 [岗位简历指南](docs/RESUME_USER_GUIDE.md)。M5.3 已实现开放题有据草稿、本人编辑审核与导出，见 [开放题指南](docs/ANSWERS_USER_GUIDE.md)。

## 快速启动

使用 Node.js **24.11.1** 与 pnpm **10.26.2**，依赖由 `pnpm-lock.yaml` 固定。

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm dev
```

- API：`http://127.0.0.1:4318`。
- 网页连接中心：`http://localhost:3000`，只提供配对诊断，不保存个人简历副本。
- 浏览器：在 `chrome://extensions` 开启开发者模式，加载 **`apps/extension/dist`**；修改后重新构建并在扩展管理页重新加载。
- 打开扩展弹窗，点击 **打开个人资料库**，进入扩展自己的工作空间。

API 构建后可单独运行 `pnpm --filter @formpilot/api start`。当前只允许监听回环地址，扩展固定请求 4318 端口。

## 使用 M1 资料库

1. 建立至少 10 位口令的资料库。口令只用于本地加密，忘记后无法恢复；请导出加密备份。
2. 导入文字 PDF、UTF-8 TXT，或粘贴简历文本。原文件与原文块先加密保存到本地，不会自动发送给模型。扫描件/无文本 PDF 会提示改用 TXT 或手动输入。
3. 配置服务端 `.env`（参考 `.env.example`）：DeepSeek 地址、`deepseek-flash`、供应商密钥及独立本地访问令牌。当前工作区已按用户指定写入 `.env`，文件列入 `.gitignore` 且权限为 600；不要覆盖已有密钥或把它提交到仓库。
4. 将 `.env` 中 **FORMPILOT_API_TOKEN** 的值填入扩展“本地 API 访问令牌”，点击连接。这里填的是本地服务令牌，**不是模型密钥**。模型密钥只在后端读取。
5. 对照供应商、模型、数据政策与本次文本范围，勾选授权后解析。只有当前文档的提取文本和块标识发送给模型，不上传原文件或其他文档。
6. 每条候选都需对照原文确认。修改形成新版本并标记用户来源；冲突须明确拒绝或保留，年月不能由模型补成具体日。不同经历独立分组，跨文档同一经历可手动映射后重新审核。
7. 可以手动补充事实、查看历史、导出加密备份、修改口令及删除全部资料。备份恢复只允许在没有现存资料库时执行；备份仍需要原口令。

锁定会清除页面中的资料和解密密钥，并通知其他资料库窗口锁定。关闭/刷新页面需要重新解锁，静置 15 分钟自动锁定。浏览器中只保存密文；PBKDF2 参数按设备校准，AES-GCM IV 每次重新生成。

解析是异步任务，启动前本地保存请求和授权检查点。页面关闭后可解锁、连接服务并恢复查询；任务结果保存后立即请求服务端清理。服务端结果只存在内存，最多保留五分钟；服务重启或过期会明确报错，再次发送文本需重新授权。API 会话最长 30 分钟，浏览器重启后需重新连接。

文件限制：PDF/TXT 不超过 10 MB，TXT 另限 1 MB，PDF 不超过 100 页，提取文本不超过 10 万字符；最多 20 份文档，资料库 JSON 不超过 50 MB。PDF 使用扩展内置 worker 本地提取，不提供 OCR，也不承诺复杂多栏版面的阅读顺序。

## 使用 M2 网页扫描

1. 打开要扫描的网页，点击浏览器工具栏的 FormPilot 图标，授予当前标签页临时访问权限。
2. 在弹窗选择目标标签页并点击 **开始扫描**。需要完整结果时点击 **打开扫描侧栏**，也可从浏览器侧栏菜单选择 FormPilot。
3. 核对字段标签、当前值、必填/禁用/只读状态、选项、日期/长度/格式约束与经历分组。重复标签按页面分组展示，附件、自定义控件及歧义字段明确标为人工处理。
4. 点击 **定位到网页** 可滚动并临时标出对应控件；不会聚焦、点击、修改字段或触发 input/change。可展开人工标注，为识别不清的字段补充含义，网页标签不会改变。
5. 新增/删除经历、修改控件属性、用户输入及 SPA 步骤变化会更新预览。DOM 结构变化会使旧标注与旧快照失效；仅改变当前值不会改变结构指纹，但会生成新快照，旧定位请求仍被拒绝。
6. 结束时点击 **停止扫描**，清除当前页面的扫描内存和会话元数据。关闭页面、导航或扫描会话超过 15 分钟后，需要重新启动。更新/重新加载扩展后请刷新目标网页。

M2 不要求解锁简历库，不调用模型或上传表单。字段值只在当前页面隔离脚本和扩展预览内存中保留；`chrome.storage.session` 只保存 tab/task/期限等授权元数据，不存字段值。支持顶层页面原生控件，iframe/Shadow DOM、自定义选择器、文件上传等有明确人工边界；浏览器内部页与未授权网站会拒绝扫描。

扫描最多 250 个字段、每字段 200 个选项，预览消息约 1.5 MB 上限；超限明确不完整或失败。原生表单完整采集不等同整个招聘网站已适配。当前腾讯、字节、小米只有官方入口与原生通用能力记录，详见 [站点能力表](docs/SITE_CAPABILITIES.md)。真实登录后的申请表需要有授权的账号和人工对照，尚未宣称通过。

## 使用 M3 填充计划

1. 服务端 `.env` 增加独立的 `FORMPILOT_DATA_KEY`（随机 32 字节十六进制，64 字符）。当前工作区已生成，保留既有配置并重新启动 API；密钥不进入客户端。
2. 解锁资料库、确认事实并连接本地 API。在目标页面启动 M2 扫描后，返回资料库的“M3 · 填充计划审核”。
3. 展开本次数据范围，确认供应商、模型与政策，勾选本次发送授权并生成计划。
4. 审核可填/待补充/需审核/人工处理/跳过。缺项答案、字段修改和新增经历默认仅本任务；原值不同时明确保留或替换，多经历歧义先选对应经历。
5. 每次补答/修改产生新版本。解决 review 后选择要批准的 fill 字段，点击批准，显示“已批准，可执行填写”。接着可进入 M4；申请不会自动提交。
6. 页面或资料变化、扫描关闭/过期会阻止旧计划批准。可同步已保存计划；服务重启后重新连接同工作空间即可恢复 24 小时内计划。资料库刷新后要重新解锁。

扩展计划与历史在 Vault 中加密；服务端检查点在 `.runtime/formpilot.sqlite` 加密保存，最多 24 小时。删除全部资料在连接时同步清理服务端工作空间；离线时明确提示未确认清理。服务端数据密钥需保管，变更后无法恢复旧计划。详见 [API 契约](docs/api/README.md) 与 [M3 报告](docs/reports/M3.md)。

## 使用 M4 填写与核验

完成 M3 审核后，在资料库“M4 · 填写与核验”点击“填写已批准字段”，保持资料库解锁和目标页面打开。逐项查看原值、目标、实际值与失败原因；失败项可在守卫仍有效时单字段重试。可停止后续填写、同步加密检查点、查看历史报告或条件撤销。页面/资料/用户编辑变化时保护原值，状态未知不自动重放。

附件、自定义控件、条款等在网页中人工处理，可从计划卡片定位。字段回读成功不能视为申请提交或企业服务器保存成功。首站选择小米，登录后实际申请表尚未验收；详见 [M4 操作说明](docs/M4_USER_GUIDE.md)、[标准任务口径](docs/evaluation/M4_STANDARD_TASKS.md) 和 [M4 报告](docs/reports/M4.md)。

## 测试与复验

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm test:integration
pnpm build
pnpm exec playwright install --with-deps --no-shell chromium
pnpm test:e2e
```

普通浏览器回归使用受控模型替身，默认跳过真实付费模型测试；不把替身结果作为真实解析证据。显式执行真实模型技术验证（全部使用虚构样本）：

```bash
pnpm smoke:model
FORMPILOT_LIVE_MODEL_TEST=1 pnpm test:e2e
```

本机缺少系统浏览器运行库，已在 `/tmp` 准备临时运行库和中文字体；本轮实际复验命令见 [M1 报告](docs/reports/M1.md)。CI 使用标准系统依赖安装方式，未接入真实模型密钥。

`pnpm check` 包含四个 API Schema 漂移检查、类型检查、lint、单测、接口/HTTP 集成测试与构建。构建检查实际配置的服务端密钥及测试标记不出现在客户端产物；日志不记录原文、答案、模型输出、令牌或请求 URL 参数。模型耗时与 token 用量有记录，实际费用以供应商账单为准。

## 工程结构

```text
apps/web             网页连接中心
apps/extension       扩展资料库、连接诊断与 MV3 worker
apps/api             Fastify 接口、异步解析、加密计划与执行检查点
packages/contracts   共享 schema、运行时校验与冻结的 v1 接口契约
packages/domain      文档、证据、事实历史、日期、实体与填充计划规则
packages/local-store Dexie / IndexedDB、加密、CAS、备份与删除
packages/ai          DeepSeek JSON 适配器与证据二次校验
packages/browser-engine 原生扫描、分组、快照、受限执行、回读与撤销
packages/config      严格配置、日志字段白名单、共享 TS 配置
tests                单元、接口、真实浏览器与虚构测试样本
```

用户已授权删除 `legacy/`，旧展示页、旧扩展及内嵌源码副本已移除，新工程只从一份扩展源码构建。用户已删除 `.git`，本轮不重新创建版本仓库。
