# M5.3：开放题回答

从已确认事实中选择与问题有关的材料，生成有引用的回答草稿。模型负责选材，程序保留完整事实原值并组织草稿；本人修改、保存并审核后，才能通过应用复制或导出。回答不会自动写入申请表或成为个人事实。

## 使用步骤

1. 执行 `pnpm build`，重启本地 API，在扩展管理页重新加载扩展，解锁个人资料库。确保事实已确认、冲突已解决，JD 提取项已核对。
2. 用既有本地 API 令牌连接服务，展开 **M5.3 · 开放题回答**，选择目标岗位。填写问题，或选择优势、动机、项目经历、挑战等示例问题后调整。
3. 明确勾选本次可发送的 1～16 条事实。只有当前无冲突的确认事实可选；联系方式、姓名、性别、证书编号和薪资不进入可选字段。可以使用“选入前 16 条可用事实”，但仍需逐项检查关联性。
4. 展开 **核对本次发送内容**。本次发送问题、所示岗位标题/公司/要求、选中事实的值及引用标识；不发送原始文件、材料证据、其他未选事实或历史答案。若事实值中含有不希望发送的信息，应先修改资料或取消勾选。
5. 核对供应商、模型和数据政策，单独勾选本次授权，点击 **授权生成开放题草稿**。改变问题、选择、岗位、资料或供应商后，需重新授权。
6. 生成完成后展开 **查看生成草稿与引用**，检查事实版本、材料对照与 JD 关联。模型引用必须等于选中事实的全文，不能截掉否定词或限制。岗位引用仅供对照，不代表符合要求。
7. 在 **本人修改后的答案** 中调整成真实、自然的回答，并保存。只增删首尾空白不算修改。原文没有说明的动机、挑战、措施或结果需要本人提供真实内容，不能猜测补齐；程序不自动验证本人新增的陈述。
8. 核实内容后点击 **我已修改并核实答案，审核此版本**，再复制或导出 TXT。导出仅含最终正文，不包含内部引用标识、原始材料和审批说明。粘贴到申请页面后仍需人工核对。

未经修改的生成草稿、未保存修改、未审核或已过期答案，其复制/导出按钮保持禁用。界面仍允许查看草稿，以便本人审阅与修改。

## 取消、恢复和版本

- 正在生成时可点击 **取消开放题生成**。应用尝试中止并删除服务端任务，移除本地检查点，迟到结果不会重新写入；服务不可达时，无法确认删除的服务端缓存按 5 分钟期限清理。这不承诺模型供应商已删除接收内容，供应商保留规则以本次政策为准。
- 生成中锁定、关闭页面或断网后，可重新解锁、连接 API，再点击 **恢复开放题生成**。恢复只查询原任务；即使启动响应丢失，也按原请求标识只读查找，不重新发起付费调用。
- 服务重启或结果过期时，取消本地检查点，重新核对内容并明确授权新生成。原请求不会由恢复操作自动重发。
- 每份答案独立保留问题、岗位/档案版本、选中事实和材料快照、本次授权记录、原始生成草稿与本人修订。锁定、重启和加密备份恢复后仍可查看。
- 修改正文后清除审核；恢复历史产生新修订，不恢复审核。最多保留 10 个历史修订、30 份答案和待生成任务、3 个本地检查点。
- JD、个人资料、计算日期或规则变化使旧答案过期，不能继续审核或通过应用复制/导出。使用 **将此问题与事实带入重新生成**，核对当前可用事实并重新授权；旧答案保留。
- 可删除单份答案及历史。删除来源岗位会清理该岗位的答案和本地检查点，服务端运行任务可能仍需取消或等待到期。删除整个资料库清除全部本地内容。

## 能力边界

本轮是可追溯的选材与草稿功能，没有让模型自由编造叙事或业绩。材料不足、空引用、未知引用或不完整原文会明确失败。最多选取 6 条完整事实组织单次草稿，正文上限 6000 字符。事实属于不同实体时分别组织，不将多段经历拼成同一项目。

生成草稿的引用证明材料来源；本人改写后的内容由本人核实，引用不能自动证明新增陈述。当前不提供无人审核的答案填充，也不把答案审核当作 M4 表单执行批准。

投递记录、多站点专有控件适配及真实简历/小米申请表业务验收仍待后续。
