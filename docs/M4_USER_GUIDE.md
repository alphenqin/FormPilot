# M4 填写、核验与撤销

本版在资料库中提供执行入口，扫描侧栏继续用于扫描与对照。系统不会提交申请。

## 开始填写

1. 更新后运行 `pnpm build`，在扩展管理页重新加载扩展、刷新目标网页，并重新启动 API。保留已有 `.env` 密钥。
2. 解锁资料库，连接本地 API，确认要使用的事实。在目标页面点击 FormPilot 图标启动扫描。
3. 返回资料库生成计划，核对来源与证据。解决 review，补充必要答案、选择对应经历，明确处理网页原值冲突，然后批准所选字段。
4. 在“M4 · 填写与核验”点击“填写已批准字段”。保持资料库解锁、目标页面打开，避免同时编辑正在处理的字段。
5. 查看逐字段原值、目标与回读。只有观测窗口内一致且网页校验通过才显示“稳定回读一致”；服务端再核对报告与计划。字段回读成功不代表整张表已完成或企业服务器已保存。

未选中、缺项与人工字段保持原状。可在计划卡片点击“定位到网页”，在网页中处理附件、自定义控件、条款同意或不支持的字段。密码、验证码和支付信息不参与自动填写。

## 失败、停止与重试

- “用户已修改”会保留新值；单字段值冲突不强行覆盖其他用户输入。
- 写后清空或改写显示“值未持久化”；网页校验失败需对照网页修正。
- “重试此字段”需要当前计划仍有效、批准仍在、页面与来源执行记忆仍可用。重试生成新记录；值或编辑历史已变化时必须重新扫描、生成和批准。
- 点击“停止后续填写”停止后续字段；当前已开始的字段仍可能完成回读，已经写入的值不会自动恢复。
- 资料、页面身份或结构变化、权限失效、网络中断会阻止继续。页面刷新后不自动沿用旧计划。停止/替换扫描会结束旧执行；如需撤销，应先在原扫描会话中完成。

## 恢复与撤销

刷新资料库后重新解锁，可同步加密检查点与报告。worker 重启后仍由原页面与服务端记录核对；不会重新执行已完成字段。若仍显示进行中，点击“核对执行状态”：页面仍在运行时等待，状态丢失则标记中断，人工检查后重新扫描审核。

“撤销本次填写”逐字段比较当前值和编辑历史，只恢复没有被后来改动的值。用户改后再改回写入值，也会跳过。历史执行可展开并单独撤销；每次报告独立，不应把旧记录当作当前整张表状态。

撤销后批准失效。页面重载、标签关闭或原执行记忆丢失时不自动撤销，需人工处理；撤销也不能删除网站可能已自动保存的数据。附件不会自动上传、恢复或删除。
