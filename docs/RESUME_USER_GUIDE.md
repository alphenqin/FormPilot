# M5.2：岗位版简历

基于已核对的 JD 和已确认的个人事实，在浏览器本地生成不同岗位的简历版本。支持内容选择、经历排序、修订历史、审核和导出。正文保留事实原值；需要改写时先在事实库修订并确认，再生成新版。生成过程无需模型或 API 连接，个人经历不会因此上传。

## 操作步骤

1. 执行 `pnpm build`，在 `chrome://extensions` 重新加载扩展；重启 API 可更新能力版本。解锁个人资料库。
2. 在 **M5.1 · JD 与岗位匹配** 保存一个岗位并核对提取项；也可仅本地保存 JD，手动添加原文要求后确认。个人事实需要先确认，冲突须先解决。
3. 展开 **M5.2 · 岗位版简历**，选择目标岗位，填写可选的新版本名称，点击 **生成岗位版简历**。
4. 检查默认选入内容。系统把有匹配证据或明确关键词线索的经历优先排列；若存在相关工作/实习/项目，只默认选入这些经历，否则保留全部可选经历供审核。基本信息、教育等仍按资料组织。性别、薪资和证书编号默认不选入，可自行勾选。没有确认的事实不会出现在可选列表。
5. 在左侧勾选具体事实、上移/下移经历分组、修改版本名称；右侧即时预览正文。未选中的字段不会出现在导出正文，包括简历标题。点击 **保存简历编排**；存在未保存修改时，可放弃修改后切换版本。
6. 展开 **查看事实和岗位引用**，核对事实版本、原始材料和关联的 JD 条件。关键词相关仅作编排线索，不证明满足岗位条件；用户修订值与对照原文有区别。日期保留年/月/日精度，不补齐。
7. 确认正文与来源后，点击 **我已核对正文与来源，审核此版本**。随后可导出 Markdown 或可打印 HTML。HTML 在浏览器打开后，用打印功能另存为 PDF；项目没有直接 PDF 下载按钮。

导出文件包含所选个人资料的明文。事实引用和修订历史留在加密资料库，不出现在面向招聘方的简历正文中；需要带证据的报告可使用 M5.1 的岗位证据对照导出。

## 版本、失效与恢复

- 每份岗位简历独立绑定岗位版本、档案版本、计算日期和规则版本；不同岗位拥有独立简历，原始简历文档和事实不会被改写。
- 修改名称、内容选择或顺序后，需要重新审核。每份最多保留 10 个历史修订；恢复旧编排会生成新修订，审核状态不会恢复。
- 修改个人资料或 JD、跨计算日期、更新规则后，旧简历保留但禁止导出或继续审核。使用 **基于最新资料生成独立新版本**；原有内容选择和经历顺序尽量按事实/实体标识保留，新事实重新初选，结果必须重新核对。
- 最多保留 20 份岗位简历。选择不同已保存版本可查看旧快照；锁定、重启和加密备份恢复后仍保留来源、编排与历史。
- **删除此岗位简历及修订** 仅清除这一份简历。删除其来源岗位时，界面会明确删除该岗位的分析和所有岗位简历。原始个人资料保持保留；删除整个资料库才清除全部资料。

## 当前边界

这版定制通过事实筛选和排序完成，没有自由生成的润色段落、量化业绩或自动补齐经历。每份最多 400 条事实、80 个实体分组，每组 60 条事实，单条最多 20 项材料引用；超过限制会明确失败。

HTML 导出仅渲染转义文本，不含脚本、远程资源或自动提交逻辑。简历审核仅用于本地导出，不是招聘表单填写批准；不会自动上传简历或提交申请。

开放题已在 [M5.3](ANSWERS_USER_GUIDE.md) 实现；投递记录、多站点专有适配仍为后续工作。真实个人简历和小米登录后申请表的业务验收仍待完成。
