## M0：工程基础

功能：创建独立 pnpm 工作区和 `@formpilot/*` 包；前端、扩展与 Fastify 服务脚手架；统一 contracts、错误码、消息协议、配置、日志白名单、测试工具与 CI；`/health`、`/v1/system/capabilities`；记录旧工程保留/迁出清单，消除重复内嵌源码打包链路。仅搭建模型 Provider 接口，不提前开发简历算法和填写业务。

测试：配置和错误契约单测；health/capabilities 接口测试；web→扩展配对 ping、扩展→API 真实通信集成测试；干净安装、类型检查、lint、构建、加载解压扩展验证。不可用 API 必须明确报错，不返回伪成功。

验收：按 README 在干净环境可复现启动，前端显示真实连接状态，扩展调用真实服务；产物不含服务端密钥。记录环境、构建耗时和 health 延迟，不宣称产品业务完成。

## M1：个人经历资产库

功能：本地工作空间解锁/锁定；PDF/TXT/手动输入；本地文本提取、分块；真实模型结构化抽取；原文证据定位；事实确认与编辑；实体管理、多文档冲突、版本历史；加密 IndexedDB、备份与删除；最少的异步任务启动/查询协议以适应 worker 生命周期。

测试：证据引用真实性、未知引用拒绝、日期精度、解析异常、确认状态、版本变更、加解密与迁移单测；parse 的正常/拒绝/超时/非法输出接口测试；真实脱敏简历导入→调用真实模型→逐项确认→重启恢复集成测试。扫描 PDF 提示无可提取文本，不用虚构数据代替。

验收：至少一份有授权的真实简历建立可回溯档案；展示原文与候选差异；未确认事实不作为已确认事实输出；删除可验证。记录样本、解析耗时、失败率、模型费用与限制。

## M2：表单识别

功能：用户启动扫描、最小权限注入；原生控件适配；label/ARIA/约束/选项/当前值/分组；快照与 page_instance_id；稳定定位与结构 fingerprint；MutationObserver 动态重扫；选择首个真实目标站点并完成适配能力表。file 支持识别和人工入口，不提前承诺通用自动上传。

测试：三套表单模板的字段、约束、可见性和分组单测；快照与消息协议接口测试；加载真实扩展的扫描集成测试；动态增删、路由切换、iframe 未授权、不支持控件、重复标签与字段 ID 测试。

验收：识别目标网站主要字段，定位唯一且不可越过页面作用域；没有差别上传整页；提供字段人工标注与识别结果对照。记录字段规模与扫描 P95。

## M3：智能决策

功能：事实语义匹配、经历实体绑定、五类决策、缺项问题去重、任务答案、冲突保留/替换、字段编辑与取消、新计划版本与批准摘要、CAS 与幂等；冻结 PRD 四个 API 的 JSON Schema 并生成接口文档。

测试：语义 path、精度、实体、原值冲突、范围、版本和状态守卫单测；四个 API 的 schema、未知 ID、作用域、并发修订、幂等冲突和模型异常接口测试；资料→扫描→计划→追问→新版本→审核集成测试。此阶段不自动写网页。

验收：fill/ask/review/manual/skip 结果可解释，所有填值均可追溯；模型无权批准自身输出，旧批准失效；用户补充默认仅当前任务。模型超时或坏输出不产生可未经审核执行的值。报告计划生成耗时与降级比例。

## M4：自动填写闭环

功能：批准验证、页面/原值守卫、逐字段执行、原生及首站适配、事件触发、延迟回读、校验状态、失败报告、单字段重试、条件撤销、任务恢复、执行锁；不提交申请。准备最终用户操作文档和能力边界。

测试：执行前置条件、控件写入/回读、执行锁、撤销与恢复单测；verify 的报告/计划一致性接口测试；真实 Chromium 加载扩展的全链路集成测试；完成下列 12 项边界和 30 个标准任务。真实授权网站需另留人工验收证据，本地模板不能替代真实网站验收。

验收：首次填值正确率 ≥95%，正确自动覆盖率 ≥80%，PRD 五项零容忍错误全部为零；失败与人工项明确展示，不能将网页填写成功显示为投递成功。记录逐字段执行/核验耗时、稳定窗口、浏览器版本、适配器版本和未支持控件。

## 12 个必测边界的落点

| # | 用例 | 阶段与预期 |
|---|---|---|
| 1 | 现居城市不是意向城市 | M3：缺少意向时 ask，不能复用现居值 |
| 2 | 年月不能补具体日 | M1/M3：保留 precision，date 字段 ask/review |
| 3 | 网页原值冲突 | M3/M4：保留原值，用户明确替换并批准后才写入 |
| 4 | 多简历事实冲突 | M1/M3：显式 conflict，未解决不得自动采用 |
| 5 | 多段实习不交叉 | M3：每组唯一 entity_id，歧义 review |
| 6 | 项目时间异常 | M1/M3：结束早于开始提示异常，不能自动修造时间 |
| 7 | 合理时间重叠 | M1/M3：跨经历重叠不直接判错 |
| 8 | React 写后清空 | M4：稳定窗口与最终回读返回 failed |
| 9 | 页面变化后旧计划 | M2/M4：snapshot/page/fingerprint 变化阻断执行 |
| 10 | 虚构事实/字段 ID | M1/M3/M4：校验引用集合与作用域，拒绝非法引用 |
| 11 | 模型超时/非法输出 | M1/M3：degraded 明确，不生成无依据可执行值 |
| 12 | 用户改后撤销 | M4：值比较 + 编辑标记保护，不能覆盖用户新值 |

## 标准任务与评估

10 份脱敏简历 × 3 套表单模板形成 30 个任务。每个任务附预期字段值、事实/证据引用、entity_id、决策类型、日期精度、缺失/冲突项和允许自动填写范围。样本固定版本，评估区分规则单测、带可控模型替身的回归、真实模型测试和真实网站人工验收。

首次填值正确率与正确自动覆盖率按技术方案定义；人工项、失败项、跳过项分别计数。报告分子、分母和错误字段，不能只给百分比。API 及浏览器错误路径纳入验收，不通过关键零容忍项则 M4 不通过。

## 每阶段交付报告模板

报告保存 `docs/reports/Mx.md`，包含：

1. 阶段范围、验收结论与日期。
2. 完成功能和可复现演示步骤。
3. 项目目录变化和核心代码模块。
4. 数据模型变化、迁移与兼容影响。
5. API、错误码、配置和权限变化。
6. 测试命令、环境、通过/失败/跳过项及证据。
7. 性能实测、样本量与测量条件；未测则明确未测。
8. 未解决问题、风险与验收阻塞。
9. 下一阶段拟做任务，等待阶段确认后开始。

M0 报告按实际验证记录；M1～M4 未完成时不预写完成报告，不以规划文档冒充阶段验收。

## M5.2：岗位简历定制

实现本地已确认事实筛选与编排、岗位独立版本、来源快照、修订历史、审核失效和 Markdown/可打印 HTML 导出。个人事实不上传，不自由编造或润色业绩；编辑正文走事实修订与确认。操作见 [简历指南](RESUME_USER_GUIDE.md)，验证见 [M5.2 报告](reports/M5.2.md)。开放题已在 M5.3 交付；后续投递记录、多站点及真实业务验收继续保留。

## M5.3：开放题回答

基于明确授权的已确认事实选材，以完整引用组织草稿，用户修改并审核后可复制/导出。异步任务支持取消、按任务/请求只读恢复、版本失效与加密保存。操作见 [开放题指南](ANSWERS_USER_GUIDE.md)，验证见 [M5.3 报告](reports/M5.3.md)。投递记录、多站点适配及真实业务验收仍待后续。
