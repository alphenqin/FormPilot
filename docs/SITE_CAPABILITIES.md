| 原生 date、month                        | 当前值及 min/max/step；不转换精度                               | M4 已实现原生填写与回读，待真实站点验收 |
| 原生 select / multiple                  | value/label、禁用选项、当前选择；最多 200 个选项                | M4 已实现原生填写与回读，待真实站点验收 |
| 原生 radio                              | 按 form 与 name 聚合，保持选项与当前值；跨组/重复值标为人工核对 | M4 已实现原生填写与回读，待真实站点验收 |
| 原生 checkbox                           | 布尔勾选状态、名义选项值与 required                             | M4 已实现原生填写与回读，待真实站点验收 |
| file                                    | 识别 required、accept、multiple；不读所选文件名/内容            | 需人工选择                              |
| disabled / readonly                     | 明确记录不可编辑，允许只读定位核对                              | 不写入                                  |
| 自定义 combobox/listbox/contenteditable | 识别为人工控件，不假称原生可操作                                | 未支持                                  |

模板验证使用三套完全合成表单，不复制真实候选人数据或声称复刻以上公司的申请表。

## M4 首站：小米（2026-11-17）

用户已明确选择小米。只读复核了 [官网首页](https://hr.xiaomi.com/) 和 [机会页](https://hr.xiaomi.com/opportunities.html)：当前公开机会页展示职位关键词搜索、地点与招聘类型，不能把搜索控件作为申请表验收。本轮没有登录账号、填入小米真实申请表或触发投递。

通用原生执行、校验、重试与条件撤销已实现，默认稳定窗口 500 ms，逐字段校验来源/页面/原值。file、自定义控件与 iframe/Shadow DOM 维持人工边界，条款不得自动勾选。小米专有控件、登录后申请表和网站自动保存行为尚未验证；registry 的 native-controls-only 仍是能力边界，不是整站通过标记。

后续人工验收按 [M4 操作说明](M4_USER_GUIDE.md) 记录实际页面、版本、支持/失败/人工字段及撤销结果，禁止使用账号密码或带令牌链接作为证据。其他两站仍只有 M2 候选与公开入口记录。
