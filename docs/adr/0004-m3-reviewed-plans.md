# ADR 0004：可审核计划与加密短期检查点

状态：采纳，2026-11-17。用户已删除 `.git` 并明确授权开始 M3，不重建仓库。M1 真实简历、M2 实际公司申请表的验收继续待完成。

模型只进行字段语义分类，严格输出 field_id/path/entity_id；填写值由规则取自已确认事实或用户任务答案。已知语义与模型冲突时审核，未知模型语义要求用户确认；日期精度不足追问，选项歧义、格式约束、事实冲突和异常时间不猜测。经历按分类和页面父组绑定，多实体歧义要求用户选择；新增经历只属于当前任务。

计划内容不可变，每次 resolve 新建 plan_id、递增版本并重算 SHA-256。批准与失效是独立状态变化，拥有 state_revision CAS。批准只能通过显式接口选择 fill 字段；资料修订或完整快照引用变化让批准失效。浏览器在批准前重新读加密资料库和实际扫描结果，避免依赖 React 旧状态。跨窗口更新要求重新解锁。

API 使用内置 node:sqlite，避免增加数据库驱动。迁移位于 `apps/api/migrations`，拒绝高于当前版本的库。AES-GCM 加密上下文、历史和幂等响应，索引采用 HMAC，目录 0700、库 0600。服务端密钥与模型、本地访问令牌独立。客户端仍使用既有 Vault 加密，新增可选 fill_tasks 字段，v1 旧备份兼容。

幂等先持久预留，再调用模型，最终 CAS 状态和响应在同一事务提交；同进程合并并发，重启后未完成预留标为中断，不自动重付费。撤销会话清理该工作空间计划；异步迟到结果不能复活已删除数据。有效期 24 小时，定时清理；解析结果仍保持五分钟内存期限。

四个 PRD 接口以共享 Schema 导出并校验漂移。verify 只冻结未来协议，M3 对有效请求也返回 501；不把客户端自报结果当执行成功。M4 的逐字段写入、回读、撤销和执行锁未实施。
