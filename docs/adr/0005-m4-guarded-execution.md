# ADR 0005：受限执行、检查点与条件撤销

状态：采纳。日期：2026-11-17。用户授权开始 M4，首个真实目标为小米招聘。真实申请表与测试数据范围尚未完成验收；先交付本地闭环，不伪装站点适配完成。

## 授权与执行边界

执行接口只接受计划引用、操作类型和字段 ID。服务端依据已保存的批准计划生成带随机 lease token、单调 epoch、十分钟期限的执行包，不接受客户端自行指定填充值。开始时精确绑定原始快照，后续允许自身填值引起 snapshot ID 变化，仍严格绑定 task/tab/frame 0/page_instance/DOM fingerprint。新计划、错页、错字段、原值冲突、失效批准均阻断。

扩展 options 是当前资料解锁和执行控制入口，worker 编排、内容脚本操作 DOM。options 的 Port 在每字段前核对最新 Vault 工作空间和资料版本；锁定或关闭控制页会停止后续字段，已经开始的单个字段仍记录回读。外部网页只开放既有 pair/ping，不能执行；content 只接受本扩展 worker 的执行消息，消息不含任意脚本、CSS 或目标 URL。

同窗 Vault 读写排队并按计划版本/状态版本合并任务，报告同步不覆盖资料或新批准，跨窗口仍用 CAS。SQLite v2 增加工作空间执行锁，原 v1 原地升级，锁在重启后仍有效。页面执行器在异步预检完成后同步重查活动执行与 epoch，防止两个预检同时通过后双写。重复 execution_id 不再次执行，重试生成新记录，限已失败字段；字段值或编辑历史变化则保护原值。

## 检查点与回读

每字段 before 检查点持久化成功后才可写入；再检查页面与实际原值，然后调用原生原型 setter，派发 input/change，绝不点击提交按钮。默认稳定观察窗口 500 ms、100 ms 采样，核验预算 2000 ms；观察期间发生不一致不会被最后一次相同值掩盖。读取 value/checked/selected、ValidityState、aria-invalid；结束前再次回读全部已执行字段。

after 检查点、最终报告、序号和 epoch 均由服务端校验。最终报告可以降级旧成功项，不能把未确认或失败的检查点升级成功。verify 要求报告与持久检查点逐项一致、范围与批准一致，返回 REVIEW 与 application_submitted=false；只校验客户端报告，不能独立观察第三方网页或证明企业服务器保存。

执行包、报告和历史沿用 AES-GCM 加密 SQLite 与 Vault。chrome.storage.session 仅保留 workspace/task/tab/execution/epoch/期限等调度元数据，字段值不存入其中。每任务保留最近 20 次执行记录，计划有效期仍为 24 小时。网络或权限失效停止后续写入，不做盲目重放；恢复先查看报告和页面，未知状态标中断并要求重扫审核。

## 撤销与人工边界

撤销需要来源执行的页面内记忆，比较当前值与 written target，并检查自写入以来的编辑计数；用户改后又改回相同字符串也不能覆盖。写前检查点等待期间再次编辑，仍须阻断。恢复原值后同样回读；恢复必填字段原先的空值可以成功，不因此声称表单合法。撤销后批准清除、任务回到 DRAFT，后续填写须重新生成审核。

停止/替换扫描、导航或关闭标签会结束旧执行并清理其执行锁，离线时保留恢复引用且锁仍有期限。页面重载丢失编辑记忆时不自动撤销，不将未知状态猜为成功；撤销不覆盖网站服务器可能已自动保存的历史。file、条款同意、密码/验证码/支付、只读、禁用、自定义组件与未授权 iframe/Shadow DOM 维持人工边界。相关结构改变暂停整份旧计划；单字段值冲突保护该字段，独立字段可继续。

小米专有组件和实际申请表待登录后的授权验证；不编造选择器、账号结果或网站保存成功。通用原生实现与合成标准任务只构成工程证据。
