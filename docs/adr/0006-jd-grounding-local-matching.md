# ADR 0006：JD 原文约束与本地经历匹配

日期：2026-11-17。状态：采用，范围 M5.1。

用户选择先完成 JD、岗位匹配和经历证据对照。模型用于提取岗位内容；匹配由可审查的本地规则执行，不让模型输出个人能力、匹配分或批准。

模型输出必须通过严格 schema，所有 quote 必须是 JD 中唯一的连续片段，属性值与关键词必须来自引用；偏移、标识和条件规则由程序生成。复合条件不能丢弃限定词后自动判定满足，无法确定的条件保留人工审核。用户审阅后才允许匹配，修改提取项使其重新待确认。

模型仅接收 JD text；个人事实和证据不发送给模型。匹配只使用当前已确认且无冲突事实，遵守实体、日期精度、技能名称和意向/现居语义边界。缺少数据不等于明确不具备。结果提供四类状态、解释、事实版本和证据引用，不给综合资格结论。

岗位、修订、分析和解析恢复检查点纳入既有 AES-GCM 资料库；原有无 career 的资料及加密备份继续有效。岗位更新使用预期修订校验，Vault 读改写队列合并最新个人资料和填写任务。结果绑定岗位与档案修订、计算日期、规则版本；变化后保留历史并提示重新计算。

JD 异步 API 用业务 session 绑定工作空间，校验正文授权摘要、供应商、模型、政策、时效与幂等键。结果仅存内存 5 分钟，删除或撤销中止调用，超时及迟到结果不能复活。服务端重启不自动重付费。

代价：规则覆盖有限，复杂职责与行业语义需要用户核实；提取完整性仍由用户对照原文审阅。后续版本可新增经过独立验收的条件，不能将当前相关文字线索升级成已满足。
