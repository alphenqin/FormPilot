# ADR 0007：本地岗位简历与事实快照

日期：2026-11-17；状态：采用；范围：M5.2 简历定制。

PRD 要求岗位版简历保留原始资料、只使用真实经历、记录修改、支持多版本审核与导出。本轮继续实现简历定制，采用本地可核对的筛选与排序，不增加向模型发送个人事实的流程。

简历生成只读取当前无冲突的已确认事实。按 entity_id 分组，结合岗位匹配证据与明确关键词线索进行初选与排列；关键词不得升级为满足要求。Latin 技能词检查边界，JavaScript 不作为 Java 的相关线索。正文复制事实原值，日期保留 precision，不增加业绩数据。正文编辑通过既有事实修订/确认流程完成，简历编辑器负责选入、排序和版本名称。

每份简历保留不可变事实/证据快照、JD 条件、岗位/档案版本及规则/计算日期，编辑状态与审核独立。名称、选择、排序变更生成修订并清除审核；恢复历史仅恢复编辑状态，不恢复批准。独立新版本保留父版标识、尽量沿用内容选择与顺序，原版不覆盖。预期修订阻止过期写入。

审核在 Vault 的同一读改写队列中读取最新资料，导出再次读取与检查版本、事实来源及审核状态。资料/JD/日期/规则变化后保留旧版但禁止导出，必须重新生成并审核。定制状态为 career.resumes 可选字段，沿用 AES-GCM、现有备份与恢复；旧资料可直接读取，不增加密钥、数据库版本或权限。旧程序不保证能够读取新增字段，应升级后恢复新备份。

导出支持纯文本 Markdown 和静态可打印 HTML。值经过文本转义，HTML 使用禁止脚本和网络资源的 CSP；内部引用与审核状态不混入面向招聘方的简历正文。HTML 可由浏览器打印成 PDF，当前不提供直接 PDF 导出或云端排版服务。

代价：输出是结构化事实版简历，没有模型自由润色；事实库质量和用户审阅决定正文质量。复杂职责判断、真实网站上传和投递仍单独验收，不将本地简历审核当作表单执行批准。
