# ADR 0008：开放题选材、完整引用与本人审核

日期：2026-11-18；状态：采用；范围：M5.3。

PRD 要求开放题建议结合岗位与真实经历，并由用户修改后使用。自由模型叙事难以自动证明每一项能力或业绩。因此模型仅选择已授权事实、完整引用与 JD 对照标识；固定程序按实体组织草稿，不允许模型输出任意新陈述或批准。引用必须等于事实原值全文，保留否定词、限定词与日期精度；未知标识、截取改写、空引用、额外总分被拒绝。

只有当前无冲突的确认事实可选，且姓名、联系方式、性别、证书编号、薪资字段被排除。每次显式选择 1～16 条，展示发送范围，独立 answer_generate 授权绑定供应商、模型、政策、摘要与时刻。上游仅收到问题、岗位要求与所选事实，不收到原始文档、证据或完整档案。

异步任务按 session 工作空间隔离，校验幂等与授权；结果只存服务端内存 5 分钟，超时默认 60 秒。新增按请求 ID 的只读查找，解决启动响应丢失时的恢复：恢复不重发生成 POST，过期/重启后需要用户重新授权。取消/撤销中止任务，迟到结果不可复活。

本地答案、授权、快照、检查点和历史沿用加密 Vault。本人编辑与模型草稿分开标记，修改后清除审核，只有本人修改并单独审核的当前版本可经应用复制/导出；空白变化不能绕过修改要求。资料、JD、日期或规则变化后保留历史但阻止使用。审核与导出读取最新资料，预期修订防止并发覆盖。

代价：生成内容是有据草稿，不是自动完成的自由叙事；动机、挑战和结果在资料不足时必须本人补充。程序不自动证明本人新增陈述，UI 明示该边界。复制/导出仅输出纯文本，答案审核不产生网申填写批准或自动提交。
