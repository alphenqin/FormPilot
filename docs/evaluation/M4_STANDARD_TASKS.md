# M4 标准任务与指标口径

数据集版本：`synthetic-1`。10 份完全虚构的简历 × 3 套本地模板，30 个实际 Chromium DOM 执行任务。不是 10 份真实脱敏简历，也不是小米申请表的复刻。真实资料与站点验收另列待完成。

源数据：[固定样本生成器](../../tests/fixtures/m4-standard.ts)。每个 sample-01～sample-10 的姓名、邮箱、手机号、城市、学校、学历和两段实习都有确定值，原文证据由固定文本产生并经领域校验，再逐项确认。日期保留年月精度，两段实习时间有合理重叠。解析使用固定候选与规则，不调用付费模型；不把受控候选当真实模型解析质量。

模板与预期：[basic](../../tests/fixtures/forms/standard-basic.html)、[education](../../tests/fixtures/forms/standard-education.html)、[internships](../../tests/fixtures/forms/standard-internships.html)。领域规划、来源/证据校验、实体绑定、浏览器执行器和 DOM 都使用实际代码；检查点传输采用测试回调。生产扩展、API、加密保存与恢复另由扩展全链路用例验证。

| 模板        | 每任务可填写目标分母 | 有资料且可自动执行 |                   保留 ask | 始终人工   | 显式审核动作                       |
| ----------- | -------------------: | -----------------: | -------------------------: | ---------- | ---------------------------------- |
| basic       |                    6 |                  5 |   可到岗天数（简历未提供） | 附件、条款 | 明确批准替换网页旧姓名             |
| education   |                    8 |                  7 | 具体毕业日（资料只有年月） | 附件、条款 | 常规计划批准                       |
| internships |                   10 |                 10 |                          0 | 附件、条款 | 显式绑定两段实习，不按数组顺序猜测 |

30 个任务共 240 个标注可填写目标，20 个缺项/精度项仍计入覆盖率分母；60 个附件/条款人工项单列。审核后计划预计执行 220 个字段。测试在执行前独立比对路径、实体、精度、来源与预期值，执行后比对真实 DOM 和最终报告。规则无法自动确定的经历绑定和原值替换记录为人工审核动作，不混入模型自动判断成绩。

首次正确率 = 首次执行且最终回读正确字段 / 首次执行字段。正确自动覆盖率 = 正确自动执行字段 / 标注可填写目标。这里衡量**用户完成计划审核后的本地执行**；不衡量无人审核端到端成功率或真实站点覆盖率。

复现：

```bash
pnpm build
pnpm test:m4
# 已运行整套浏览器测试后，可只汇总已有 30 个记录：
pnpm evaluate:m4
```

标准任务产物为 `test-results/m4-standard-*.json`，包含每任务 expected/actual、字段决策、实体、人工动作和逐字段检查点时间；汇总为 `test-results/m4-summary.json`。需要正好 30 个不同的样本/模板组合，指标脚本对错误、自动提交、首次正确率不足 95% 或覆盖率不足 80% 失败。检查点间耗时来自真实浏览器时间，稳定窗口默认 500 ms；真实站点延迟另测。

最终实测结果见 [M4 报告](../reports/M4.md) 与交付的 JSON 证据。
