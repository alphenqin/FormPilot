## 复现步骤

见 [README](../../Readme.md#快速启动)。执行 pnpm install --frozen-lockfile、pnpm build、pnpm dev；加载 apps/extension/dist；在弹窗检查 API，生成配对码并到 http://localhost:3000 连接。API 地址为 http://127.0.0.1:4318。

## 目录与核心模块

- apps/api/src/app.ts：接口、响应校验、脱敏错误与元数据日志；server.ts：环境配置、启动和信号退出。
- apps/extension/src/background/：内部消息来源校验、外部配对与会话校验、真实 HTTP health 客户端。
- apps/extension/manifest.ts、vite.config.ts：最小权限声明及多入口构建；content 当前不执行页面业务。
- apps/web/src/main.tsx：配对输入、请求关联与响应校验、扩展/API 连接状态。
- packages/contracts：共享 TypeBox schema、协议版本 1、错误契约与运行时校验。
- packages/config：配置校验、日志白名单与共享严格 TS 配置；packages/ai：Provider 端口。
- tests/integration、tests/e2e、.github/workflows/ci.yml、scripts/verify-artifacts.mjs：接口、网络、浏览器及构建验证。

旧文件保留/迁出清单和方案具体取舍见 [ADR 0001](../adr/0001-m0-workspace.md)。新工作区不引用旧品牌图片，使用 FormPilot 文字标识。

## 数据、API、配置与权限

未创建简历、事实、任务等业务数据库，未修改既有个人浏览器资料。新扩展使用独立 ID，旧扩展资料不会自动迁移。配对码及短期会话存 chrome.storage.session，网页令牌仅在内存；不存模型密钥。浏览器重启清理会话，worker 内存不是唯一权威。

配对码为 128 位随机数，有效期两分钟、一次性消费；会话令牌为 256 位随机数，绑定精确 origin 与 tab ID，30 分钟失效，关闭标签页清理。网页通道不开放内部 health 消息、任意 URL、资料或填写命令；ping 只返回 API 状态摘要。

扩展权限为 activeTab、scripting、storage、sidePanel 及回环 API host。manifest 不注册全站 content_scripts，不申请 all_urls。Web origin 在 worker 校验为 http://localhost:3000 且只接受顶层 frame；API 默认只监听回环地址，无跨域业务接口。

API 的 model_available=false；未实现业务接口返回 404。模型环境变量仅在后端示例配置中预留；构建脚本验证客户端产物没有密钥配置名或泄露测试标记。API 查询参数白名单、请求体大小和响应 schema 均有校验，错误不回显正文。

系统为 Ubuntu 22.04.5，缺少 libnspr4/libnss3/libasound2 及中文字体；sudo 安装因需要密码失败。授权后仅下载 Ubuntu 软件包并解压到 `/tmp/formpilot-browser-libs/root`，测试进程通过临时环境变量加载，无系统目录修改。普通 `pnpm test:e2e` 在此机器仍需先解决运行库；本轮实际命令为：

```bash
FONTCONFIG_FILE=/tmp/formpilot-browser-libs/fonts.conf \
LD_LIBRARY_PATH=/tmp/formpilot-browser-libs/root/usr/lib/x86_64-linux-gnu \
pnpm test:e2e
```

标准环境使用 README 的 Playwright `install --with-deps --no-shell chromium` 安装方式，CI 已配置。临时库或字体删除后需要重新准备，不能把本轮通过解释为系统已永久配置。

- 干净源码目录的 Vite Web 构建 1.08 s、扩展 Vite 构建 2.08 s；包含本地机器负载影响。API esbuild 与 content 构建未单独计时，不将上述相加冒充总构建耗时。

## 限制与下一阶段

M0 仅包含本地开发通信与工程验证，不提供个人资料、PDF、加密仓库、表单识别或自动填写；未进行真实招聘网站测试。无业务账号、云服务、数据库或生产部署。React Router、PDF、SQLite 和未使用的业务包按后续阶段引入，避免空实现。

M1 拟实现本地工作空间解锁/锁定、PDF/TXT/手动输入、真实模型解析与证据定位、事实确认/冲突/版本、加密存储、备份/删除与可恢复异步任务。进入前需确认 M0 验收与 M1 范围，并确定首发模型供应商、模型版本及处理政策；真实简历样本需具备授权。
