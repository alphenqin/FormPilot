## 功能与复现步骤

1. `pnpm install --frozen-lockfile`、`pnpm build`、`pnpm dev`，加载或重新加载 `apps/extension/dist`。
2. 打开目标网页，在浏览器工具栏点击 FormPilot，获得 activeTab 临时权限。
3. 在弹窗确认目标标签页，点击“开始扫描”；打开扫描侧栏查看全部字段。
4. 核对标签/ARIA、当前值、required、disabled/readonly、选项、日期/长度/格式约束和经历分组。文件、自定义控件、歧义与超限项明确人工处理。
5. 点击“定位到网页”滚动并临时标出字段；展开人工标注补充字段含义。不会设置网页值、点击或聚焦控件，不发 input/change，不提交申请。
6. 手动增加/删除经历、修改字段或切换 SPA 步骤后观察新快照；旧定位引用拒绝。结束后“停止扫描”清除快照与会话，导航、关闭及 15 分钟期限也会清理或要求重启。

详细说明见 [README](../../Readme.md#使用-m2-网页扫描)。本轮未进入 M3 填写计划或 M4 网页写入。

## 数据、身份与失效规则

每个会话绑定 task_id、tab_id、frame 0 与期限；每个文档/SPA URL 身份变化更新 page_instance_id。字段/定位标识通过 WeakMap 绑定实际 DOM 节点，重复标签保持独立，radio 依原生 form/name 聚合，跨组或相同 value 的歧义明确人工核对。节点替换即使同 HTML id 也产生新身份；不执行来自网页或模型的任意 CSS/脚本。

SHA-256 结构指纹包含身份、标签、类型、选项、约束、分组及 adapter version，不包含当前值。值变化形成新快照、指纹保持；旧快照、旧页、错任务、错 tab/frame 或未知字段都不能定位。定位前重新采集核对，不能依赖观察器是否已触发。

MutationObserver/input/change 去抖约 120–180 ms，800 ms 补偿无事件值/URL 变化，预览约 1300 ms 刷新。无关装饰变化不会使有效快照失效。人工标注只在扫描内存中，结构变化清除标注，手动标注也产生新快照。

原始 URL 只在隔离脚本内存比较；对外 origin/route 去除 query、普通 hash 和高熵/邮箱路径段，不保存带 token 完整 URL。字段值、快照、标注不写磁盘或 chrome.storage；session 存储只保留任务、tab、期限。worker 停止后从元数据联系原页面恢复，完整导航/刷新不沿用旧快照。

## API、错误与权限

M2 不新增 HTTP 扫描/上传接口，不调用模型、不上传网页或资料；原 M1 API 保持兼容。共享 schema 新增内部 scan.start/get/refresh/stop/locate/annotate 和内容 initialize/read。外部网页仍只有 pair/ping，不接受扫描、定位或执行消息。

权限保持 activeTab、scripting、storage、sidePanel，持久 host 仍只有 `http://127.0.0.1/*`，不新增 all_urls/全站 content_scripts/iframe 权限。浏览器在没有页面权限时拒绝实际注入。定位引用不替代授权。错误区分 PERMISSION_DENIED、UNSUPPORTED_PAGE、STALE_SNAPSHOT、PAGE_CHANGED、FIELD_NOT_FOUND、SNAPSHOT_EXPIRED、SCOPE_DENIED、SCAN_LIMIT_EXCEEDED。

敏感输入依据 type、标签、name、autocomplete 等规则在取值前排除；这属于启发式识别，实际站点仍需人工核对。附件不访问文件名/内容，iframe 不递归，open Shadow DOM 仅提示，closed Shadow DOM 不作完整识别承诺。支持原生 text/textarea/email/tel/date/month/select/radio/checkbox 的识别；number/url 等未列入首版自动操作承诺的控件仍可记录但标人工。M2 本身不执行任何填写。

环境：Ubuntu 22.04.5、Node v24.11.1、pnpm 10.26.2、Chromium 141.0.7390.37、Playwright 1.56.1。复用已在 `/tmp` 准备的浏览器运行库与中文字体，没有更改系统依赖。

| ----------------------- | ----------------------------------------------------------------- |
| `pnpm typecheck`        | 通过                                                              |
| `pnpm lint`             | 通过（交付文档后已复查）                                          |
| `pnpm test`             | 34 项通过；含新增 8 项结构、URL、站点域名与扫描协议测试           |

worker 恢复用 CDP ServiceWorker.stopWorker 实际停止，观测 stopped 生命周期后发送新消息恢复，而非只删除 JS 变量。恢复后 snapshot/task 保持；页面刷新后旧引用拒绝。定位和标注期间网页的 input/change/submit 计数保持零；扫描不发 POST，session 存储不含字段值。测试扩展使用生产 manifest，未追加测试外站权限；回环模板注入依赖现有回环 host 权限，实际外站 activeTab 人工操作仍需在真实申请表中验收。

## 性能与证据

真实 Chromium 的 100 个原生字段，20 次强制扫描，最近一次 P50 **6.0 ms**、P95 **9.7 ms**。包含 DOM 标签/约束/分组读取、前后投影核对与 SHA-256；不包含网站加载、Chrome 消息往返或预览轮询。仅本地合成模板，无真实招聘站点 P95 或覆盖率结论。

扫描上限为 250 字段、500 分组、每字段 200 选项、消息约 1.5 MB。超限显示不完整/人工处理或明确失败。未对上限容量、复杂站点或高频 DOM 抖动做压力测试。

证据：[实际扩展扫描预览](assets/m2-scan-preview.png)、[三站公开入口元数据](assets/m2-public-sites.json)。图中为完全虚构样本，不含真实候选人数据。
