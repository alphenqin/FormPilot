# M3 填充计划与审核实施报告

日期：2026-11-17。用户明确授权开始 M3，并说明主动删除 `.git`；本轮不重建仓库。范围为计划与审核，M4 网页写入、核验、撤销、自动提交均未实施。M1 真实简历与 M2 登录后实际公司申请表验收继续待完成。

## 交付

- 语义 path 匹配、五类决策、问题去重、任务答案、经历绑定、任务新增经历、日期精度/选项/格式/事实冲突/时间范围校验。规则区分现居与意向，模型只分类，不产生填写值。
- 审核界面显示网页原值、候选、来源与证据；可保留/替换/编辑/取消/转人工，补答默认 task 范围。每次 resolve 形成新版本，明确批准所选可填字段；资料或完整页面快照变化后失效。
- 持久幂等预留、并发请求合并、状态 CAS、重启恢复、旧批准防重放、删除期间迟到结果防复活。SQLite 中上下文、历史和响应均 AES-GCM 加密，身份索引 HMAC；24 小时期限，约一分钟清理周期。
- 四个 API 的请求/响应 JSON Schema 导出并纳入 `pnpm check`。verify 有效引用也返回 501，M3 不伪造实际执行成功。

操作步骤见 [README](../../Readme.md#使用-m3-填充计划)，接口与状态规则见 [API 契约](../api/README.md)，设计见 [ADR 0004](../adr/0004-m3-reviewed-plans.md)。

## 核心目录与兼容

`packages/contracts/src/fill.ts` 为计划/答案/批准/核验/本地任务 schema；`packages/domain/src/planning.ts` 为确定性规划与修订规则；`apps/api/src/planning.ts`、`plan-store.ts` 与 `apps/api/migrations/0001_plans.sql` 为接口和加密检查点；`apps/extension/src/workspace/PlanPanel.tsx` 为审核界面。没有增加第三方运行依赖，SQLite 使用 Node 24 内置模块。

Vault v1 增加可选 fill_tasks，旧备份可继续读取；任务历史随加密备份导出，最多 30 个任务、每个 40 个历史检查点，资料库原有 50 MB 限制继续生效。新增读取最新状态守卫，其他窗口改动会要求重新解锁。API 的 M1 异步解析协议保持兼容，结果仍只在内存保留五分钟。

服务端新增独立 `FORMPILOT_DATA_KEY`，当前 `.env` 已生成并保持 0600；不输出或写入客户端。生产 API 缺少此密钥时计划能力关闭，health 和 M1 保持可用。数据库目录 `.runtime` 已忽略，目录 0700、数据库 0600；保管密钥，更换后不能恢复旧计划。删除全部资料在已连接时同步清理服务端；离线会提示未确认清理，不能声称服务端已删除。

权限保持原 activeTab/scripting/storage/sidePanel 与回环 host，无新增权限。资料库 options 页面仅新增 scan.get/locate 访问，不能启动、标注或停止扫描；外部网页不开放扫描接口。M3 用户授权后，快照/已确认事实/证据送到本地 API，模型只接收字段（含原值和选项）、分组和经历名称。字段语义文本仍是不可信输入，模型输出受 schema/引用校验。

新增规则测试覆盖：现居/意向、重复问题、日期精度、原值保留/替换、不同经历不交叉、嵌套分组、任务新增经历、原文证据、异常时间与合理重叠、选项歧义、五类决策、未知模型引用、降级、摘要、冲突、危险正则与数值范围/步长。

新增接口测试覆盖：完整 plan/resolve/approve、旧版本与假批准、作用域、并发幂等、CAS、批准失效和防重放、同意摘要、快照时效、证据、模型超时/拒绝/伪造引用、SQLite 加密和重启恢复、中断请求不自动重付费、删除清理、日志脱敏、迟到结果防复活、verify 的 M3 边界与缺配置能力关闭。

实际 Chromium 扩展用例使用生产 manifest 和受控模型，验证资料→扫描→原值冲突确认→任务补答→新版本→批准→刷新解锁恢复→页面变化失效。网页原值及 input/change/submit 计数证明流程没有写入；用户最后主动编辑网页用于触发失效。受控模型不等同真实模型验收。

真实 DeepSeek 合成样本：`node --import tsx --env-file=.env scripts/smoke-plan.ts`，3 个字段得到 fill/fill/ask，degraded=false，耗时 **1096.1039 ms**，输入 **1095 tokens**、输出 **64 tokens**，样本量 **1**、降级 **0/1**。只发送固定虚构字段与经历标签，无真实简历；该测量不构成真实场景成功率或 P95，也不代替供应商费用账单。
