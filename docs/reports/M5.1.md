# M5.1：JD 与岗位经历证据匹配

日期：2026-11-17。范围依据：用户“开始 M5”，并选择“先完成 JD 与岗位匹配”。

本轮交付 JD 解析、条件审阅、岗位匹配与经历证据对照；完整 M5 仍在进行。实际招聘业务验收保留，不能以合成页面代替小米真实申请表或真实简历验收。

## 完成功能

- 粘贴 JD 或在用户授权的当前标签页读取可见正文。排除导航、表单、可编辑区和显式私密/隐藏区；来源 URL 脱敏、正文上限与截断提示，无新增扩展权限。
- DeepSeek 仅解析当前 JD 文本。严格结构与原文唯一引用校验；程序生成偏移和规则，模型不得输出个人事实、匹配分或批准。
- 岗位属性与硬性/核心/加分条件逐条展示、定位、确认；支持分类/级别/关键词修订、删除和从原文补充要求。修改后重新确认，旧版本保留。
- 已确认事实本地匹配，四类逐项结论、理由、事实版本、entity_id 和原始材料引用。技能名称/熟练度、学历、年限、精度、重叠经历与意向城市有保守规则，复杂语义保留人工审核。
- 结果绑定岗位、个人档案、计算日期和引擎版本。版本变化提示过期，历史不会冒充当前结论；支持导出 Markdown 证据对照。
- JD、分析和恢复检查点纳入既有加密 IndexedDB/备份。事实与 M4 任务更新保留最新岗位；旧无 career 备份兼容。异步任务手动恢复、取消，服务重启/过期不会自动重付费。

## 核心模块与接口

`packages/contracts/src/career.ts`：来源、提取、岗位、审阅、分析与恢复契约；`packages/domain/src/career.ts`：原文校验、版本与本地规则；`packages/ai`：JD 专用提示与 text-only 输入；`packages/local-store`：兼容加密资料更新；`apps/api/src/career.ts`：异步任务、作用域、授权、幂等、超时与取消；扩展 `background/career.ts` / `workspace/CareerPanel.tsx`：读取和完整交互。

辅助 API：POST `/v1/career/jd/parse`；GET/DELETE `/v1/career/jd/jobs/:id`。契约导出见 [career.json](../api/v1/career.json)。旧四项接口不改形状；capabilities stage 为 M5.1，增加 JD 解析和本地匹配能力。无新环境变量，无 SQLite schema 变更，个人匹配不上传。

资料库 `career` 为可选 v1 扩展，含岗位、分析和待解析检查点，旧资料可直接解锁。最多 20 个岗位、每岗位 10 个旧版本、合计 60 份分析、3 个待处理检查点。服务端 JD 任务内存保存 5 分钟，默认 60 秒超时；同工作空间 2 个运行任务，全服务最多 20 个缓存任务。

## 使用与限制

按 [M5.1 操作指南](../M5_USER_GUIDE.md) 重建、重启 API 并重新加载扩展，在资料库展开 M5.1 入口。原文提取可能遗漏，用户需审阅完整性；确认不等于满足。系统不输出总分或录用资格，不将 JD 生成个人事实或 M4 填充值。

泛化页面读取不等于站点适配验收。全日制、行业相关经验、复杂职责、签证等未支持条件保留人工核实。简历定制、开放题、投递记录与多站点仍未实现；小米实际申请表和真实个人简历联合验收继续待完成。
