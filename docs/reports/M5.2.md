# M5.2：岗位版简历定制

日期：2026-11-17。依据：用户在了解剩余功能后要求“继续实现”；本轮继续完成简历定制。M5 整体仍有开放题、投递记录和多站点专有适配待实现，真实简历与小米实际申请表验收继续保留。

## 交付内容

- 基于已审阅 JD，在浏览器本地初选、排列已确认且无冲突的事实。保持事实原值、实体归属与日期精度，原始文档和事实不回写。JD 匹配证据和词语相关线索分别标识，JavaScript 不作为 Java 线索；不生成新业绩或项目数据。
- 工作/实习/项目按相关证据初选；没有相关经历时保留全部供用户选择。基本信息、教育等按资料组织，性别、薪资和证书编号默认不选入。所有确认事实均可在编辑器中核对和选择，不能将关键词线索当作符合条件。
- 勾选字段、调整经历顺序、修改版本名称、实时预览、保存修订、单独审核。正文改写通过既有事实修订并确认后再生成。导出只含选入字段及已有岗位标题/公司，内部引用留在资料库。
- 各岗位独立版本、事实/证据快照和最多 10 个历史修订。恢复历史会产生新修订并清除审核。基于最新资料创建独立新版本，保留父版、原有内容选择与实体顺序；新事实重新初选。
- 名称/选择/顺序变更清除审核。岗位、档案、计算日期或规则变化后保留原版，禁止旧版继续审核和导出。审核在同一 Vault 队列读取最新资料，导出再次读取并校验，避免并发事实更新下的过期批准。
- Markdown、静态可打印 HTML 导出；HTML 在浏览器打印为 PDF。没有直接 PDF 下载按钮。字段文本转义、无外部资源/脚本、CSP 阻断执行，不把个人内容当作 HTML 或 Markdown 指令执行。
- 简历及历史纳入既有加密 IndexedDB 和备份。支持锁定、重启恢复和删除；删除岗位时明确级联清理相关分析与岗位简历。不会自动上传或提交申请。

## 结构、兼容与权限

`packages/contracts/src/resume.ts` 定义来源快照和版本契约；`packages/domain/src/resume.ts` 实现初选、排序、审核、来源校验和导出；`ResumePanel.tsx` 提供编排、预览、历史与操作入口。

`career.resumes` 是可选字段，旧资料和加密备份可直接由新版读取，无新增密钥或 SQLite schema 变更。新增内容不保证被旧版程序识别，恢复新备份时应使用新版。上限 20 份简历、每份 400 条事实/80 个分组、每组 60 条事实、每事实 20 项材料引用；超过上限明确失败，不截取出伪完整正文。

Vault 的 updateCareer 额外向更新回调传入队列内最新 ProfileState，用于审核守卫；旧单参数调用继续兼容。事实、填写任务和职业资料并发更新保留最新 career。恢复时不仅验证 schema，也核对简历快照与原始已确认事实/证据；快照不能改值或跨实体。

capabilities stage 为 M5.2，增加 resume_tailor_local 标记，无新 HTTP 接口、模型操作或扩展权限。原四项业务接口及 JD 异步接口保持兼容，无新增付费模型调用。离线生成不依赖 API 或模型供应商。
